# 依赖清单

这个项目的卖点之一是「数据留在自己机器上」，所以依赖越少越可信。这份清单的作用是：**让你在装之前就知道会引入什么。**

## 运行时依赖

| 组件 | 运行时依赖 | 说明 |
|---|---|---|
| **Hub**（`hub/`） | **0 个** | 只用 Node 内置模块，`npm start` 不需要 `npm install` |
| **插件**（`dsh-feishu/`） | 1 个 | `@larksuiteoapi/node-sdk`，飞书官方 SDK |
| **Web 前端** | 0 个 | 构建产物是静态文件，运行时不加载任何第三方脚本 |

### 插件唯一的运行时依赖

| 包 | 版本 | 许可 | 用途 |
|---|---|---|---|
| `@larksuiteoapi/node-sdk` | `1.76.0`（精确锁定） | MIT | 飞书长连接与消息卡片 |

版本是**精确锁定**的（没有 `^`），避免自动升级引入行为变化。

## 构建依赖（不进运行时）

| 包 | 版本 | 许可 | 用途 |
|---|---|---|---|
| `preact` | `^11.1.1` | MIT | 前端框架 |
| `vite` | `^8.3.5` | MIT | 前端构建 |

这两个只在 `npm run build` 时用，产物里没有它们。

## 可选组件

| 组件 | 什么时候需要 | 说明 |
|---|---|---|
| `dsh-turbo` 原生二进制 | 想要更快的 DSH 会话 | 仅 macOS，缺失时自动回退到普通模式 |
| Docker | 用容器部署 Hub | 不是依赖，只是一种部署方式 |

## 运行环境

- **Node.js >= 20**（`engines` 字段已声明）
- macOS 或 Linux；Windows 未验证

## 供应链说明

- **Hub 故意不引入任何第三方包**，包括框架。这是有意的：它是对外暴露的那一面，依赖越少，攻击面越小。
- 插件的依赖只有一个，且是飞书官方发布的 SDK。
- 没有 postinstall 脚本，没有从网络下载二进制。
- 升级依赖时优先看 diff，不只是看版本号。

## 更新这份清单

改了 `package.json` 的 `dependencies` 就必须同步改这里——这是发布检查清单的一部分。

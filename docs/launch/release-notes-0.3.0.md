这是第一个"别人照着 README 就能用起来"的版本。

## 亮点

**一条命令启动控制台**

```bash
docker run -d --name dsh-hub -p 8080:8080 \
  -e HUB_TOKEN=<你的密码> \
  -v dsh-hub-data:/data \
  ghcr.io/oscarka/dsh-hub:0.3.0
```

镜像支持 `amd64` 和 `arm64`，Intel 机器、Apple Silicon、NAS、树莓派都能跑。

**配对码接入，不用手抄地址和密码**

控制台的「添加电脑」里生成一个 6 位码，电脑上执行一条命令就能接入；同一个码可以加多台，默认 5 分钟有效。

**手机扫码登录**

电脑上登录后显示二维码，手机扫一下直接进，不用输密码。

**多 Harness 支持**

| | 看会话 | 发指令 | 停止 | 手机审批 |
|---|:---:|:---:|:---:|:---:|
| DSH | ✅ | ✅ | ✅ | ✅ |
| Antigravity IDE | ✅ | ✅ | ✅ | ✅ |
| Claude Code | ✅ | ✅ | ✅ | 计划中 |
| Codex | ✅ | ✅ | ✅ | 计划中 |

做不到的功能不会显示按钮。

**可选：飞书**

不配飞书也能用；配了之后，任务完成、需要审批时可以直接推到飞书。

## 破坏性变更

**`HUB_TOKEN` 现在是必填的。**

之前不设 token 会跳过鉴权（等于谁都能访问）。这个版本起，没有 token 直接拒绝启动。升级方式：

```bash
# 旧容器
docker stop dsh-hub && docker rm dsh-hub

# 新容器，记得带 -e HUB_TOKEN 和 -v 数据卷
docker run -d --name dsh-hub -p 8080:8080 \
  -e HUB_TOKEN=<你的密码> -v dsh-hub-data:/data \
  ghcr.io/oscarka/dsh-hub:0.3.0
```

**数据目录必须挂载。** 之前默认写在容器的临时目录里，重启就丢。现在默认 `/data`，请挂一个卷。

## 修复

- 公网部署时配对接口的限流可被伪造请求头绕过
- 一键接入脚本默认指向作者的演示实例，改为必须显式指定
- 容器以非 root 用户运行
- 补齐健康检查，编排平台能感知服务状态

## 已知限制

- 手机审批目前只有 DSH 和 Antigravity 支持；Claude Code 的官方扩展点已确认可用，计划支持；Codex 需要切换到常驻服务模式，在探索
- 只支持单实例部署（状态在进程内存里）
- Windows 未验证，目前面向 macOS 与 Linux
- 电脑关机或睡眠后，手机无法连接

## 升级步骤

1. 备份数据卷
2. 拉新镜像
3. 带上 `HUB_TOKEN` 和 `-v` 重新启动
4. 手机上用新地址重新登录（地址变了的话）

# 90 秒演示：分镜与录制

## 目标

让一个没听过这个项目的人，在 90 秒内明白三件事：

1. 人在外面，任务还在电脑上跑
2. 手机能看到它在干什么
3. 需要批准时，手机上点一下就继续

**不要讲架构，不要讲技术栈。** 只演"我怎么用它"。

---

## 准备

| 项 | 要求 |
|---|---|
| Harness | **必须用 DSH**（只有它能演审批，Codex/Claude 没有） |
| 任务 | 找一个会触发审批的真实任务，比如"改一个文件并运行测试" |
| 数据 | 清掉无关会话，只留 1–2 个，画面干净 |
| 隐私 | 关掉通知横幅；路径里不要出现真实用户名；终端字号调大 |
| 屏幕 | 手机开勿扰模式，状态栏时间调成整点（可选，但更干净） |

**先完整跑一遍**，确认审批一定会弹出来。演的时候卡住，比不演更糟。

---

## 分镜

| 时间 | 画面 | 操作 | 字幕 |
|---|---|---|---|
| 0–8s | 电脑：任务在跑，终端滚动 | 无 | AI 在电脑上跑任务 |
| 8–15s | 镜头拉远 / 切到门口 | 人拿手机离开 | 但你得走了 |
| 15–25s | 手机：锁屏，收到推送 | 点开通知 | 它需要你批准一条命令 |
| 25–40s | 手机：控制台，任务详情 | 缓慢下滑，展示当前步骤 | 在手机上看到它在做什么 |
| 40–55s | 手机：审批卡片 | 停留 3 秒，让观众看清命令 | 要执行什么，写得很清楚 |
| 55–65s | 手机：点"批准" | 点一下 | 点一下 |
| 65–80s | 电脑：任务继续，跑完 | 无 | 它就继续跑了 |
| 80–90s | 片尾 | 无 | 仓库地址 + 一句话 |

**节奏**：每一屏至少停 2 秒，让人看清。宁可少演一个功能，也不要快进。

---

## 录制方法

**方案 A（推荐）：手机 + 电脑分别录，后期做画中画**

- 电脑：QuickTime 屏幕录制，1080p
- 手机：系统自带录屏（iOS 控制中心 / Android 录屏），1080p
- 剪辑：手机画面放大占主位，电脑画面缩到角落做背景

**方案 B：只录手机**

适合没有剪辑时间的情况。缺点是"任务在电脑上跑"这个前提要靠字幕交代。

**不要用**：模拟器 + 假数据。观众能看出来，而且和真实体验不符。

---

## 导出规格

| 用途 | 格式 | 规格 |
|---|---|---|
| README 首屏 | GIF | 宽 960，**≤ 5 MB**，15 fps |
| 社交平台 | MP4 | 竖版 1080×1920，H.264 |
| 仓库 Release | MP4 | 横版 1920×1080 |

**GIF 控制在 5 MB 以内**是硬要求。超过之后 README 加载明显变慢，很多人直接关页面。

压缩顺序：先减帧（15 fps 够用）→ 再缩宽度（960 够用）→ 最后减色（128 色）。

---

## 剪辑要点

1. **前 3 秒必须有事发生**，不要放 logo 片头
2. 关键动作（点批准）加一个轻微的放大或高亮
3. 全程无旁白，靠字幕；字幕放底部，字号够大
4. 片尾停 2 秒再结束，别戛然而止

---

## 录完自检

```
[ ] 90 秒以内
[ ] 每一屏都停够 2 秒
[ ] 没有真实姓名、路径、token 出现在画面里
[ ] GIF 小于 5 MB
[ ] 在手机上看一遍（大多数人会在手机上看）
[ ] 关掉声音看一遍，能看懂
```

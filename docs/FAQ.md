# 常见问题

这些是实际被问得最多的问题。答案尽量直说，包括不好听的部分。

---

## 开始使用

### 必须先装 DSH 吗？

不必须，你可以单独或混合使用下面任意一款工具：

| | 看会话 | 发指令 | 停止 | 手机审批与多选题 | 实时插话 |
|---|:---:|:---:|:---:|:---:|:---:|
| DSH | ✅ | ✅ | ✅ | ✅ | ✅ |
| Antigravity IDE | ✅ | ✅ | ✅ | ✅ | ✅ |
| OpenAI Codex | ✅ | ✅ | ✅ | ✅ | ✅ |
| 腾讯 WorkBuddy | ✅ | ✅ | ✅ | ✅ | ✅ |
| Claude Code | ✅ | ✅ | ✅ | 计划中 | ❌ |

DSH、Antigravity IDE、OpenAI Codex 与腾讯 WorkBuddy 均已支持**完整远程控制**（含手机审批、提问卡片与运行中实时插话）；Claude Code 目前按轮次续聊（能看、能发指令、能停止，暂不支持手机审批与实时插话）。

电脑上没装的工具不会显示点不动的按钮，界面会自动隐藏不支持的操作。

### 手机要装 App 吗？

不用。用浏览器打开 Hub 地址就行，也可以「添加到主屏幕」当 App 用。

但有个前提：**「添加到主屏幕」和锁屏推送都要求 HTTPS**。用 `http://192.168.x.x:8080` 这种地址，浏览和操作都正常，只是这两项用不了。这是浏览器的规定，不是项目缺功能。

### 电脑要一直开着吗？

是。任务在你自己电脑上跑，Hub 只负责中转，不替你执行。

电脑睡眠或关机，手机就连不上。

### 支持 Windows 吗？

目前没有验证过。

一键接入脚本是面向 macOS 的（用 LaunchAgent 做开机自启），Linux 也能手动跑；Windows 需要自己起后台进程，属于待补的部分。

### 能同时管几台电脑？

可以接多台，在控制台里切换。没有硬性上限，实际受 Hub 所在机器的内存限制。

## 部署与费用

### 一定要部署到云上吗？

不一定。Hub 放在哪，决定了你**在哪个网络下能用**：

| Hub 放在 | 手机在哪能用 | 成本 |
|---|---|---|
| 自己的电脑 | 同一个 Wi-Fi | 0 |
| 家里的 NAS / 服务器 | 同一个 Wi-Fi | 设备成本 |
| Google Cloud Run | 任何网络（4G/5G/Wi-Fi） | 闲置缩容到 0，免费额度内几乎为 0 |
| 云服务器 / Railway | 任何网络 | 服务器或平台费用 |
| 本地 + 隧道 | 任何网络 | 0（隧道免费） |

「不用部署」和「在外面也能用」是互斥的，只能选一个。

### Railway 是免费的吗？

不是长期免费。

- 新账号有 30 天、一次性 $5 的试用额度
- 试用结束后是 Free 计划，**每月只有 $1 额度**
- 这个 Hub 是常驻服务，0.5 GB 内存按 Railway 的计价约 **$5/月**

所以长期跑基本等于要 Hobby 计划（$5/月）。**不要把它当免费托管用**，三天后额度耗尽服务会停。

### 国内能用 Tailscale 吗？

登录那一步要访问它的官网，国内通常能打开但慢，有时候需要代理。

登录之后，设备之间一般能直连；打洞失败会走它的中继服务器，国内可能不稳。可以自建中继，但要折腾。

所以国内用户更稳的选择是：**自己有服务器就直接部署**，没有就用国内的内网穿透服务，或者用 Railway 这类平台。

### 有完全免费的方案吗？

有，但要接受限制：

- **只在家用**：Hub 跑在自己电脑上，0 成本
- **出门用**：国内内网穿透的免费版，通常有限速或限流量
- **有域名**：Cloudflare 隧道免费
- **免费 PaaS 额度**：各家政策经常变，用之前自己确认一下

### 为什么不直接提供一个现成地址？

因为那意味着运营方能看到你的会话内容。

这个项目的前提是「Hub 是你自己的」——你的数据存在你选的地方，项目本身不向任何服务器上报任何东西。

如果你想要开箱即用的托管服务，那不是这个项目。

## 安全与隐私

### 数据会经过第三方吗？

取决于你把 Hub 放在哪。项目本身不向任何服务器传数据。

Hub 收到的是**任务列表、状态、步骤摘要和待审批的命令**；完整对话在你点开时才按需读取。

两种隧道有区别：

- **Tailscale**：设备之间加密直连，中间不解密
- **Cloudflare 隧道**：TLS 在 Cloudflare 边缘终止，流量会经过它的服务器

### 配对码安全吗？

手机登录配对码默认 6 位、3 分钟内有效（一次性使用）；电脑接入配对码 15 分钟内有效，且接口均有防暴力破解限流。

同时已内置两层安全隔离：

1. **强制设置 `HUB_TOKEN`**：未设置管理密码时服务端拒绝裸奔启动
2. **一机一证随时吊销**：每台电脑接入后都会签发独立的 `hst_...` 凭证并绑定 Ed25519 设备指纹，随时可在「设置 → 已接入电脑」单独吊销任意一台电脑而不影响其他设备

### 会不会上传我的代码？

不会上传到项目方。代码始终在你自己机器上。

Hub 保存的是会话元数据和待审批内容，保留多久取决于你部署的 Hub 的存储策略。

### 发现漏洞怎么报？

走 GitHub Security Advisories 私密报告，不要开公开 issue。细节见 [SECURITY.md](../SECURITY.md)。

## 能力与限制

### 为什么 Claude Code 暂时还没有手机审批？

审批需要工具本身提供常驻的「执行前询问」交互协议：

- **DSH / Antigravity IDE / OpenAI Codex (`app-server`) / 腾讯 WorkBuddy (`ACP`)**：均已通过各自原生协议完整接入手机审批、多选题卡片与运行中实时插话
- **Claude Code**：目前通过 `claude --resume` 按轮次调用，后续计划接入官方 `PreToolUse` 权限钩子

各工具完整能力矩阵见 [主 README 支持的 AI 编程工具](../README.zh-CN.md#支持的-ai-编程工具)。

### 飞书必须配吗？

不必。飞书只是一个可选的通知和审批通道，不配也能完整使用手机 Web 总控台（含 iPhone 主屏幕锁屏推送）。

### 和别的同类项目有什么区别？

三点：

1. **Hub 自托管**，数据留在你自己的机器或你自己的云账号上
2. **同时支持 DSH、Antigravity IDE、Codex、WorkBuddy、Claude 五大工具**，不是只绑一家
3. **内置微信式「按住说话」语音输入 + 原生协议审批**，出门单手就能高效遥控

不评价其他项目，按自己的需求选就行。

### 项目会一直维护吗？

单人维护的开源项目，没有 SLA，也不承诺响应时间。

MIT 许可，代码可以随时 fork 继续。

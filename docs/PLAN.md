# DSH Remote Control · 完整计划

---

## 一、定位

**一句话**：在手机上盯着并指挥你的 AI 编码任务——看进度、发指令、停止，装了 DSH 还能直接批准危险操作。

**不做的定位**：不是“又一个 ChatGPT 客户端”，也不是“托管服务”。核心卖点是**数据留在自己机器上**，控制台放哪由你决定。

---

## 二、用户流程（唯一主线）

| 步骤 | 在哪台设备 | 做什么 |
|---|---|---|
| ① | 部署平台 | 部署控制台，得到**一个网址 + 一个密码** |
| ② | **电脑** | 打开网址，输密码登录 |
| ③ | 电脑 | 页面提示“本机未接入”，给出一条**安装命令** + 一个**配对码** |
| ④ | 电脑 | 复制命令，终端执行（自动装好、自动连上、开机自启） |
| ⑤ | 电脑 | 页面自动刷新，出现这台电脑 |
| ⑥ | **手机** | 打开同一网址，**扫电脑上的二维码**登录（不用输密码） |
| ⑦ | 手机 | 看任务、发指令、批准（取决于后端能力） |

**加第二台电脑**：重复 ②–⑤，用同一个配对码（有效期内可多次使用）。

**三个东西各司其职**：网址是唯一入口，密码证明你是主人，配对码让电脑加入。

## 五、工程任务

### P0 · 安全与镜像（约 1.5 天）

| 任务 | 为什么 |
|---|---|
| 不带密码拒绝启动 | 现在没密码等于不校验，公网部署就是敞开的门 |
| 修限流绕过 | 取真实 IP，别用可伪造的那个头 |
| 多架构镜像 | 苹果电脑、NAS、树莓派都要能跑 |
| 非 root 运行 | 安全项目的基本体面 |
| 健康检查 | 挂了能自动拉起 |
| 数据卷可挂载 | 现在数据在临时目录，重启就丢 |
| 发布到公开镜像库 + 版本标签 | 用户一条命令就能拉 |
| 修一键脚本默认地址 | 现在默认连作者的云实例，别人的数据会进你机器 |

**验收**：一条命令起来；不带密码报错；重启数据还在；三种芯片架构都能跑。

### P1 · 首次体验闭环（约 2 天）

| 任务 | 为什么 |
|---|---|
| 启动时打印地址 + 密码 | 用户知道该打开哪 |
| 网页里的「添加电脑」面板 | 配对码 + 有效期 + 已加入台数 + 一行安装命令 |
| 凭码加入（不需要管理员密码） | 电脑只要一个码就能进，且限流 |
| 每台电脑独立凭证、可单独吊销 | 现在所有电脑共用一个主密码，不安全 |
| 安装时检测装了哪些工具 | 决定启用完整版还是观察模式 |
| 界面按能力表渲染 | 不显示做不到的按钮 |
| 手机扫码登录 | 手机上只需输一次网址 |

**验收**：电脑执行一条命令后自动接入；手机扫码即进；加第二台不用重启控制台。

### P2 · 部署与分发（约 1.5 天）

| 任务 | 为什么 |
|---|---|
| Railway 模板（镜像 + 数据卷 + 必填密码） | 小白的一键入口 |
| README 的 Deploy 按钮 | 点一下就能部署 |
| 编排文件（一条命令带数据盘） | 服务器 / NAS 用户 |
| 自托管文档（反代、HTTPS、NAS、树莓派） | 覆盖“有服务器”的人 |
| 演示 GIF + 截图 | 决定 README 的转化率 |

**验收**：Railway 上点一下，三分钟内看到登录页。

### P3 · 审批扩展（后续，不阻塞发布）

1. **Claude Code 审批** —— 官方有执行前钩子和权限代理，路径明确，优先做
2. **Codex 审批** —— 需要切换到常驻服务模式，工作量大
3. **通用兜底** —— 终端抓屏 + 远程按键，覆盖所有其他工具

## 九、明确不做

- ❌ **不做托管服务** —— 那会变成你最初想替代的东西
- ❌ **不做多渠道抽象**（Telegram/微信）—— 收益为零，先不碰
- ❌ **不做图形安装包**（v1）—— 签名公证成本高，目标用户会用终端
- ❌ **不做多实例/集群** —— 状态在内存里，单实例是设计前提
- ❌ **不写“即将支持”** —— 只写“计划中”，并给出技术路径

## 十、风险

| 风险 | 应对 |
|---|---|
| 公网暴露 | 强制密码 + 限流 + 失败即拒绝 |
| 平台免费额度不够 | README 明写“约 \$5/月”，不宣传免费 |
| 无盘平台丢数据 | 模板强制挂卷 |
| **门面与体验错位** | 主标题写“盯着并指挥”，审批标为 DSH 进阶能力；或发布前先接 Claude |
| 单人维护接不住 issue | 先写好“我不做什么”，24 小时内回复 |
| 对外一键脚本指向你的机器 | P0 第一件就改掉 |
